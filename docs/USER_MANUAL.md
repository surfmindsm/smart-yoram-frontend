## 1. 시작하기

### 1.1 서비스 소개

Church Round는 교회 운영을 위한 통합 관리 시스템입니다. 교인 관리부터 재정, 예배 및 소식까지 교회 운영에 필요한 모든 기능을 한 곳에서 관리할 수 있습니다.

**주요 기능:**
- 교인 정보 및 조직 관리
- 재정 및 헌금 관리
- 예배 일정 및 주보 관리
- 공지사항 발행
- 심방 및 기도 요청 관리

> **[스크린샷 위치]** 메인 화면 전체 캡처

---

### 1.2 회원가입 및 로그인

#### 회원가입

1. Church Round 웹사이트에 접속합니다
2. "회원가입" 버튼을 클릭합니다
3. 필수 정보를 입력합니다:
   - 이메일 주소
   - 비밀번호
   - 이름
   - 교회 정보
4. 약관에 동의하고 "가입하기" 버튼을 클릭합니다
5. 이메일 인증을 완료합니다

> **[스크린샷 위치]** 회원가입 화면

#### 로그인

1. Church Round 웹사이트에 접속합니다
2. 이메일과 비밀번호를 입력합니다
3. "로그인" 버튼을 클릭합니다

> **[스크린샷 위치]** 로그인 화면

#### 비밀번호 찾기

비밀번호를 잊어버린 경우:

1. 로그인 화면에서 "비밀번호를 잊으셨나요?" 링크를 클릭합니다
2. 가입한 이메일 주소를 입력합니다
3. 이메일로 전송된 비밀번호 재설정 링크를 클릭합니다
4. 새로운 비밀번호를 입력하고 저장합니다

> **[스크린샷 위치]** 비밀번호 찾기 화면

---

### 1.3 대시보드 화면 구성

로그인 후 가장 먼저 보이는 대시보드 화면입니다.

**화면 구성:**

1. **상단 헤더**
   - 메뉴 토글 버튼 (사이드바 열기/닫기)
   - Church Round 로고
   - 최근 접속 기록 버튼

2. **왼쪽 사이드바**
   - 주요 메뉴 그룹 (아코디언 형태)
   - 후원 계좌 정보
   - 문의하기 버튼
   - 사용자 프로필 및 로그아웃

3. **메인 콘텐츠 영역**
   - 대시보드 통계 및 차트
   - 최근 활동 내역
   - 빠른 실행 메뉴

> **[스크린샷 위치]** 대시보드 전체 화면 (사이드바 포함)

---

### 1.4 메뉴 안내

Church Round는 기능별로 그룹화된 메뉴 구조를 제공합니다.

#### 메뉴 그룹

1. **대시보드 & 분석**
   - 대시보드: 주요 통계 및 현황 확인

2. **교인 관리**
   - 교인 관리: 교인 등록, 수정, 조회
   - 조직 관리: 부서 및 조직 구성 관리
   - 심방 신청 관리: 심방 요청 확인 및 관리
   - 중보 기도 요청: 기도 제목 관리

3. **재정 관리**
   - 회계 관리: 예산 및 지출 관리
   - 헌금 관리: 헌금 기록 및 조회

4. **예배 & 소식**
   - 예배 시간: 예배 일정 관리
   - 주보 관리: 주보 작성 및 발행
   - 공지사항: 공지사항 작성 및 게시

5. **교회 운영 & 설정**
   - 교회 정보: 교회 기본 정보 설정
   - 일정 관리: 중요 날짜 및 일정 관리

**메뉴 사용 방법:**
- 각 메뉴 그룹을 클릭하면 하위 메뉴가 펼쳐집니다
- 한 번에 하나의 그룹만 열립니다 (아코디언 방식)
- 현재 선택된 메뉴는 파란색으로 표시됩니다

> **[스크린샷 위치]** 사이드바 메뉴 (펼쳐진 상태)

## 2. 교인 관리

### 2.1 교인 등록

새로운 교인을 등록하는 방법입니다.

#### 등록 절차

1. 왼쪽 메뉴에서 **교인 관리 > 교인 관리**를 클릭합니다
2. 우측 상단의 **"교인 등록"** 버튼을 클릭합니다
3. 교인 등록 모달창이 나타납니다

> **[스크린샷 위치]** 교인 관리 메인 화면

#### 입력 정보

교인 등록 모달은 섹션별로 접을 수 있는 형태로 구성되어 있습니다.

##### 기본 정보 (기본 열림)
- **필수 정보**
  - 이름 (한글)
  - 영문 이름
  - 생년월일
  - 성별
- **선택 정보**
  - 프로필 사진
  - 결혼 여부
  - 배우자 이름
  - 결혼 기념일

> **[스크린샷 위치]** 기본 정보 섹션

##### 교회 정보 (기본 열림)
- 직분
- 등록일
- 소속 부서
- 등록 구분 (새가족, 등록교인 등)

> **[스크린샷 위치]** 교회 정보 섹션

##### 연락처 정보
- 휴대폰 번호
- 이메일
- 주소 (우편번호, 상세주소)
- 추가 연락처 등록 가능

> **[스크린샷 위치]** 연락처 정보 섹션

##### 성사 및 전입/전출 기록
- **성사 기록**
  - 성사 종류 (세례, 입교 등)
  - 성사 일자
  - 성사 교회명
- **전입/전출 기록**
  - 구분 (전입/전출)
  - 교회명
  - 일자

> **[스크린샷 위치]** 성사 및 전입/전출 기록 섹션

##### 차량 정보
- 차량 종류
- 차량 번호

> **[스크린샷 위치]** 차량 정보 섹션

#### 저장하기

1. 모든 필수 정보를 입력합니다
2. 하단의 **"등록"** 버튼을 클릭합니다
3. 등록 완료 메시지를 확인합니다

**💡 팁:**
- 기본 정보와 교회 정보 섹션은 기본적으로 열려있습니다
- 각 섹션은 클릭하여 펼치거나 접을 수 있습니다
- 필수 항목을 모두 입력하지 않으면 저장되지 않습니다

---

### 2.2 교인 목록 조회 및 검색

등록된 교인 정보를 조회하고 검색하는 방법입니다.

#### 교인 목록 보기

1. 왼쪽 메뉴에서 **교인 관리 > 교인 관리**를 클릭합니다
2. 등록된 전체 교인 목록이 테이블 형태로 표시됩니다

**목록 정보:**
- 이름
- 생년월일
- 성별
- 휴대폰
- 직분
- 소속 부서

> **[스크린샷 위치]** 교인 목록 화면

#### 교인 검색

목록 상단의 검색 기능을 활용하여 원하는 교인을 찾을 수 있습니다.

**검색 방법:**
1. 검색창에 검색어를 입력합니다 (이름, 전화번호 등)
2. Enter 키를 누르거나 검색 버튼을 클릭합니다
3. 검색 결과가 목록에 표시됩니다

**필터 기능:**
- 직분별 필터
- 부서별 필터
- 성별 필터
- 등록 상태별 필터

> **[스크린샷 위치]** 검색 및 필터 기능

#### 페이지네이션

많은 교인 데이터를 효율적으로 보기 위해 페이지 단위로 표시됩니다.

- 페이지당 표시 개수 설정 (10개, 20개, 50개, 100개)
- 이전/다음 페이지 이동
- 특정 페이지로 바로 이동

> **[스크린샷 위치]** 페이지네이션 영역

---

### 2.3 교인 정보 수정 및 삭제

등록된 교인 정보를 수정하거나 삭제하는 방법입니다.

#### 정보 수정

1. 교인 목록에서 수정할 교인을 찾습니다
2. 해당 교인 행을 클릭합니다
3. 교인 상세 정보 모달창이 나타납니다
4. **"수정"** 버튼을 클릭합니다
5. 정보를 수정합니다
6. **"저장"** 버튼을 클릭하여 변경사항을 저장합니다

> **[스크린샷 위치]** 교인 상세 정보 모달

**수정 가능 항목:**
- 기본 정보 (이름, 생년월일, 연락처 등)
- 교회 정보 (직분, 부서 등)
- 연락처 정보
- 성사 및 전입/전출 기록
- 차량 정보

#### 정보 삭제

⚠️ **주의:** 교인 정보 삭제는 신중하게 진행해야 합니다. 삭제된 데이터는 복구할 수 없습니다.

1. 교인 상세 정보 모달에서 **"삭제"** 버튼을 클릭합니다
2. 삭제 확인 대화상자가 나타납니다
3. **"확인"**을 클릭하여 삭제를 완료합니다

> **[스크린샷 위치]** 삭제 확인 대화상자

---

### 2.4 조직/부서 관리

교회 조직과 부서를 관리하는 방법입니다.

#### 조직 관리 화면

1. 왼쪽 메뉴에서 **교인 관리 > 조직 관리**를 클릭합니다
2. 현재 등록된 조직 구조가 표시됩니다

> **[스크린샷 위치]** 조직 관리 메인 화면

#### 부서 추가

1. **"부서 추가"** 버튼을 클릭합니다
2. 부서 정보를 입력합니다:
   - 부서명
   - 상위 부서 (있는 경우)
   - 담당자
   - 설명
3. **"저장"** 버튼을 클릭합니다

> **[스크린샷 위치]** 부서 추가 모달

#### 부서 수정 및 삭제

1. 수정할 부서를 선택합니다
2. **"수정"** 또는 **"삭제"** 버튼을 클릭합니다
3. 변경사항을 확인하고 저장합니다

**💡 팁:**
- 부서에 소속된 교인이 있는 경우 삭제할 수 없습니다
- 교인을 먼저 다른 부서로 이동한 후 삭제해야 합니다

---

### 2.5 심방 신청 관리

교인들의 심방 요청을 관리하는 방법입니다.

#### 심방 신청 목록

1. 왼쪽 메뉴에서 **교인 관리 > 심방 신청 관리**를 클릭합니다
2. 접수된 심방 신청 목록이 표시됩니다

**목록 정보:**
- 신청자 이름
- 신청 날짜
- 희망 일시
- 심방 사유
- 처리 상태

> **[스크린샷 위치]** 심방 신청 목록

#### 심방 신청 상세 보기

1. 목록에서 심방 신청을 클릭합니다
2. 상세 정보 모달이 나타납니다
3. 신청 내용을 확인합니다

**상세 정보:**
- 신청자 정보
- 연락처
- 심방 희망 일시
- 심방 사유 및 요청사항
- 특이사항

> **[스크린샷 위치]** 심방 신청 상세 화면

#### 심방 처리

1. 심방 일정을 조율합니다
2. 상태를 변경합니다:
   - 접수 → 예정 → 완료
   - 또는 취소
3. 메모를 작성합니다 (심방 결과, 특이사항 등)
4. **"저장"** 버튼을 클릭합니다

> **[스크린샷 위치]** 심방 처리 화면

**💡 팁:**
- 심방 완료 후 메모를 남겨두면 다음 심방 시 참고할 수 있습니다
- 정기적인 심방이 필요한 경우 일정 관리에 등록할 수 있습니다

---

### 2.6 중보 기도 요청 관리

교인들의 기도 요청을 관리하는 방법입니다.

#### 기도 요청 목록

1. 왼쪽 메뉴에서 **교인 관리 > 중보 기도 요청**을 클릭합니다
2. 접수된 기도 요청 목록이 표시됩니다

**목록 정보:**
- 요청자 이름
- 요청 날짜
- 기도 제목
- 카테고리 (개인, 가족, 사역 등)
- 공개 여부
- 상태 (진행중, 응답됨, 종료)

> **[스크린샷 위치]** 기도 요청 목록

#### 기도 요청 상세 보기

1. 목록에서 기도 요청을 클릭합니다
2. 상세 내용을 확인합니다

**상세 정보:**
- 요청자 정보
- 기도 제목
- 구체적인 기도 내용
- 카테고리
- 공개 여부
- 요청 날짜
- 응답 여부

> **[스크린샷 위치]** 기도 요청 상세 화면

#### 기도 요청 관리

**응답/종료 처리:**
1. 기도 응답이 있거나 기도가 종료된 경우
2. 상태를 "응답됨" 또는 "종료"로 변경합니다
3. 간증이나 결과를 메모에 기록합니다

**비공개 처리:**
- 민감한 내용은 비공개로 설정하여 관리자만 볼 수 있습니다

**삭제:**
- 요청자가 삭제를 요청한 경우 삭제할 수 있습니다

> **[스크린샷 위치]** 기도 요청 관리 기능

**💡 팁:**
- 정기적으로 기도 요청 상태를 업데이트하면 좋습니다
- 응답된 기도는 간증으로 활용할 수 있습니다
- 주보에 기도 제목을 게재할 때 공개 여부를 확인해야 합니다

## 3. 재정 관리

### 3.1 회계 관리

교회 회계 및 예산을 관리하는 방법입니다.

#### 회계 관리 화면

1. 왼쪽 메뉴에서 **재정 관리 > 회계 관리**를 클릭합니다
2. 회계 대시보드가 표시됩니다

**화면 구성:**
- 월별/연도별 수입/지출 현황
- 예산 대비 집행률
- 주요 지출 항목
- 최근 거래 내역

> **[스크린샷 위치]** 회계 관리 대시보드

#### 수입 등록

1. **"수입 등록"** 버튼을 클릭합니다
2. 수입 정보를 입력합니다:
   - 날짜
   - 항목 (헌금, 후원금, 기타 수입 등)
   - 금액

### 자주 묻는 질문

**Q. 비밀번호를 잊어버렸어요.**
A. 로그인 화면에서 "비밀번호를 잊으셨나요?" 링크를 클릭하여 재설정할 수 있습니다.

**Q. 교인 데이터를 일괄로 등록할 수 있나요?**
A. 네, 엑셀 파일을 통해 일괄 등록이 가능합니다. 교인 관리 > 일괄 등록 기능을 이용하세요.

**Q. 모바일에서도 사용할 수 있나요?**
A. 관리자 화면은 PC 환경에 최적화되어 있습니다. 교인용 모바일 앱은 별도로 제공됩니다.

**Q. 데이터 백업은 어떻게 하나요?**
A. 데이터는 클라우드에 자동으로 백업됩니다. 추가 백업이 필요한 경우 엑셀 내보내기 기능을 활용하세요.

**Q. 여러 명이 동시에 관리할 수 있나요?**
A. 네, 관리자 권한을 부여하여 여러 명이 동시에 사용할 수 있습니다.
